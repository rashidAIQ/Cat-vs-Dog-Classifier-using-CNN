# 🐱 Cat vs Dog Classifier using CNN

## 📌 Overview
This project implements a Convolutional Neural Network (CNN) to classify images as either cats or dogs. The model was built using TensorFlow/Keras and trained on an image dataset to perform binary image classification.

## 🚀 Features
- Image preprocessing
- CNN architecture
- Model training and validation
- Model evaluation
- Prediction on new images

## 🛠 Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- OpenCV

## 📂 Dataset
- Dogs vs Cats Dataset (Kaggle)

## 📊 Results
- Training Accuracy: 96%
- Validation Accuracy: 94%

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/rashidAIQ/Cat-vs-Dog-Classifier-CNN.git
```

2. Install the required libraries

```bash
pip install -r requirements.txt
```

3. Run the notebook

```bash
jupyter notebook
```
